# モーション / 3D アクセシビリティ チェックリスト

エージェント・人間の両方が、演出を足すたびに確認する。  
「確認しました（SR）」は書かない。手順と観点だけ残す。

## 設計

- [ ] この演出が無くても、同じ情報が HTML で得られる
- [ ] 自動再生が 5 秒を超える場合、一時停止／停止がある
- [ ] 強い点滅・激しいシェイク・大面積フラッシュがない
- [ ] スクロールジャックをしていない（する場合は代替と decisions あり）

## `prefers-reduced-motion`

- [ ] `reduce` で GSAP / CSS アニメが実質停止または最終状態
- [ ] `reduce` で Three.js のループ／カメラアニメが止まる、または静的代替
- [ ] 減動時もレイアウトが壊れない

## 入力とフォーカス

- [ ] 再生・停止・ミュート等がネイティブボタンで操作できる
- [ ] キーボードだけで主要タスクが完了できる
- [ ] フォーカス順序が DOM 順から大きくずれない
- [ ] 正の `tabindex` を使っていない

## Canvas / WebGL

- [ ] 初期化失敗時のフォールバックがある
- [ ] タブ非表示時にレンダーループを止めている
- [ ] 意味のある操作対象が DOM 側にもある（必要な場合）

## パフォーマンス

- [ ] 初回表示で不要な大容量アセットを強制していない
- [ ] 低性能端末でページが使えなくなるほどメインスレッドを占有していない

## 文書化

- [ ] `docs/decisions.md` に導入理由と達成基準を書いた
- [ ] 適合の断定や「axe 0件＝AA」を方針ページに書いていない
