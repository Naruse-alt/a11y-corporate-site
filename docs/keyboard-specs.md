# キーボード操作仕様

各インタラクティブ要素のキーボード挙動を記録する。適用しないキーは「適用なし」と明記する。

## スキップリンク（本文へスキップ）

- **Tab**：ページ先頭で最初にフォーカスを受け取り、可視化される。
- **Enter**：`#main` へ移動する（ネイティブのページ内リンク）。
- **Space / 矢印 / Home / End / Escape**：適用なし。

## メインナビゲーション（`<nav>` 内リンク）

- **Tab / Shift+Tab**：リンク間を移動する。
- **Enter**：該当ページへ遷移する。
- **Space / 矢印 / Home / End / Escape**：適用なし（リンクのため）。
- 現在地は `aria-current="page"` と下線・太字で示す。

## テーマ切替ボタン（進歩的強化・ネイティブ `<button>`）

- **Tab / Shift+Tab**：フォーカス移動。
- **Enter / Space**：ライト⇔ダークを切り替える（`<button>` の標準挙動）。
- **矢印 / Home / End / Escape**：適用なし。
- JavaScript 無効時はボタン自体が存在せず、OS 設定に従う。

## 一次アクションボタン（リンクボタン `.button`）

- 実体はリンク（`<a>`）またはボタン（`<button>`）。
- **Enter**：常に作動。**Space**：`<button>` の場合のみ作動。
- **矢印 / Home / End / Escape**：適用なし。
