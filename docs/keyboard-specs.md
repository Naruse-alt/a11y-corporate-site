# キーボード操作仕様

各インタラクティブ要素のキーボード挙動を記録する。適用しないキーは「適用なし」と明記する。

## スキップリンク（本文へスキップ）

- **Tab**：ページ先頭で最初にフォーカスを受け取り、可視化される。
- **Enter**：`#main` へ移動する（ネイティブのページ内リンク）。
- **Space / 矢印 / Home / End / Escape**：適用なし。

## メインナビゲーション（`<nav>` 内リンク）

- **Tab / Shift+Tab**：リンク間を移動する。
- **Enter**：該当ページへ遷移する。
- **Space / 矢印 / Home / End / Escape**：適用なし（リンクのため）。
- 現在地は `aria-current="page"` と下線・太字で示す。

## モバイルメニュー：ハンバーガーボタン（進歩的強化・ネイティブ `<button>`）

- **Tab / Shift+Tab**：フォーカス移動。
- **Enter / Space**：ドロワー（`<dialog>`）を `showModal()` で開く。
- **矢印 / Home / End / Escape**：適用なし（開閉トリガーのため）。
- 開閉状態は `aria-expanded` で明示する。
- JavaScript 無効時、または `<dialog>` 非対応環境ではボタンは表示されず、
  ヘッダー内のインラインナビ（折り返し表示）で全ページに到達できる。

## モバイルメニュー：ドロワー（ネイティブ `<dialog>` モーダル）

- **Tab / Shift+Tab**：ダイアログ内でフォーカスが循環する（ネイティブのフォーカストラップ）。
- **Escape**：ドロワーを閉じる（`<dialog>` の標準挙動）。
- **Enter / Space**：内部の「閉じる」ボタンやリンクを作動させる。
- **矢印 / Home / End**：適用なし。
- 閉じると、フォーカスは開いたトリガー（ハンバーガー）へ自動的に戻る（`<dialog>` の仕様）。
- 背景（`::backdrop`）クリックでも閉じる。開いている間は背景スクロールを抑止する。

## テーマ切替ボタン（進歩的強化・ネイティブ `<button>`・アイコンのみ）

- **Tab / Shift+Tab**：フォーカス移動。
- **Enter / Space**：ライト⇔ダークを切り替える（`<button>` の標準挙動）。
- **矢印 / Home / End / Escape**：適用なし。
- アイコンのみのため名前は `aria-label` で担保（月＝ダークへ / 太陽＝ライトへ）。状態に応じてラベルとアイコンを更新する。
- JavaScript 無効時はボタン自体が存在せず、OS 設定に従う。

## パンくずリスト / フッターナビゲーション（`<nav>` 内リンク）

- **Tab / Shift+Tab**：リンク間を移動する。
- **Enter**：該当ページへ遷移する。
- **Space / 矢印 / Home / End / Escape**：適用なし（リンクのため）。
- パンくずの現在地は `aria-current="page"`（リンクではないテキスト）で示す。

## 一次アクションボタン（リンクボタン `.button`）

- 実体はリンク（`<a>`）またはボタン（`<button>`）。
- **Enter**：常に作動。**Space**：`<button>` の場合のみ作動。
- **矢印 / Home / End / Escape**：適用なし。

## FAQ アコーディオン（ネイティブ `<details>` / `<summary>`）

- **Tab / Shift+Tab**：各 `<summary>`（および回答内のリンク）間を移動する。
- **Enter / Space**：フォーカス中の `<summary>` で質問を開閉する（ブラウザ標準）。
- **矢印 / Home / End / Escape**：適用なし（ネイティブ `<details>` に矢印キーでの一括操作はない）。
- 開閉状態は要素の `open` 属性としてブラウザが管理する。独自の `aria-expanded` は付けない。
- JavaScript に依存しない。無効環境でも開閉できる。
